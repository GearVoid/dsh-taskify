# DSH Taskify

**简体中文** | [English](./README_EN.md)

面向 DeepSeek Harness Web 的任务完善插件。

DSH Taskify 可以把零散、模糊或结构混乱的输入，整理成 Coding Agent 更容易正确执行的任务说明，同时尽量保留原始意图、技术名词、路径、代码和约束。

它只会把结果回填到输入框，**不会自动发送任务**。

## 主要功能

- **一键完善任务**
  在 DeepSeek Harness 输入框右侧提供“完善任务”按钮。

- **整理任务结构**
  补全目标、执行范围、约束条件和验收标准，减少 Agent 因需求不明确而产生的偏差。

- **保护技术字面量**
  Literal Lock 会保护代码块、行内代码、文件路径、URL、IP/端口、环境变量、版本号、CLI 参数和常见代码标识符，降低模型意外改写它们的概率。

- **结合最近对话**
  可使用当前会话最近的少量已完成消息作为上下文，不读取工作区或搜索代码仓库。

- **安全回填**
  请求期间如果草稿发生变化，过期结果不会覆盖用户的新内容。

- **取消、重试与撤回**
  完善过程中可以取消；失败后可以重试；应用结果后可以恢复完善前的原始草稿。

- **保留 Slash 命令**
  `/plan` 等命令前缀保持不变，只完善命令后面的任务正文。

- **复用当前模型**
  优先使用当前会话选择的模型，不要求配置额外的 API Key。

## 安装

在包含本项目目录的位置执行：

```sh
dsh plugin --profile web add ./dsh-taskify
dsh web
```

安装后重新启动 DeepSeek Harness Web。

“完善任务”按钮会出现在输入框右侧、模型选择器和发送按钮之前。

## 使用方法

1. 在输入框中写下任务草稿，例如：

   ```text
   登录按钮还是不好看，改一下，其他东西别动
   ```

2. 点击“完善任务”。

3. 等待整理完成，结果会自动回填到输入框。

4. 检查内容后手动发送；如果不满意，可以点击“撤回”恢复原文。

## 按钮状态

| 状态 | 行为 |
| --- | --- |
| 空输入 | “完善任务”不可用 |
| 可完善 | 点击后开始整理当前草稿 |
| 完善中 | 显示静态状态图标和“完善中…”，点击可取消 |
| 已应用 | 点击“撤回”恢复原始草稿 |
| 应用后编辑 | 可以再次完善 |
| 失败 | 显示错误提示，可以重试 |

## 工作方式

```text
当前草稿
   ↓
解析 Slash 命令
   ↓
保护代码、路径和其他字面量
   ↓
结合有限的最近对话
   ↓
调用当前会话模型
   ↓
校验并恢复受保护内容
   ↓
确认草稿没有被用户修改
   ↓
回填输入框（不会自动发送）
```

## 安全与隐私

- 不读取工作区文件
- 不搜索代码仓库
- 不读取 `.env`、SSH Key 或本地凭据文件
- 不访问额外的第三方服务
- 不自动发送或提交完善后的任务
- 最近对话仅保留有限文本，并过滤常见凭据形状
- 包含 Reference Chip 的草稿在当前版本中不会被完善

## 兼容性

- DeepSeek Harness `0.1.0-rc.6`
- Web Profile
- 不修改 DeepSeek Harness 本体或 Agent Preset

DeepSeek Harness 目前仍处于快速迭代阶段，后续版本可能需要同步适配。
